# Kebijakan Keamanan

axxcalender adalah situs statis tanpa backend; data pengguna hanya disimpan
di `localStorage` browser masing-masing.

Jika kamu menemukan celah keamanan (misalnya XSS), mohon jangan membuka
issue publik. Gunakan fitur **Report a vulnerability** di tab
**Security → Advisories** pada repository ini, atau hubungi pemilik repo
melalui GitHub.
